# realtek: add support for Horaco ZX530S-8S

Add a dedicated DTS and image profile for the eight-port SFP+ HORACO ZX530S-8S. The RTL9303-based device boots through the original U-Boot, installs into the stock 12 MiB RUNTIME region and provides persistent OpenWrt configuration.

The port uses existing switch/PCS/SFP drivers, reads the original MAC through BDINFO NVMEM, configures hardware port LEDs from the stock board profile and maps the front reset button to active-low internal GPIO5 with the standard handler. Other stock flash regions remain read-only. Network defaults are generated by the target without private VLAN or MTU settings.

Installation uses serial U-Boot and an initramfs loaded at 0x82000000, followed by verified off-device backups and sysupgrade. No stock web factory image or bootloader replacement is provided. The commit message contains the installation procedure.

Validation on one RTL9303 revision B unit covers RAM/flash boot, per-unit MAC, all eight ports at 1G, 10G on ports 2/5/6/7/8, VLAN forwarding, jumbo traffic, persistence and upgrade configuration retention. The owner verified port illumination and reset GPIO polarity and reported correct operation of the final combined build. Near-10G throughput is owner-reported rather than a formal benchmark.

Stock restoration and destructive factory reset were not explicitly tested. Other revisions and every module/speed combination are outside the recorded coverage. The supplied baseline is 443e267bdb923ad32c4184ddd757744e5f07f1e4; disclose any rebase and subsequent validation when submitting.
