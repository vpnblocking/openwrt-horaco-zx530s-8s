# HORACO ZX530S-8S — OpenWrt device support

Working community port for the eight-port SFP+ HORACO ZX530S-8S. The owner reports the final build operating correctly after installation. It includes the verified port LED configuration and the front reset button mapped to OpenWrt's standard handler.

This package describes the current working implementation for community testing and upstream review. It is not an official OpenWrt release or an accepted upstream change.

## Hardware and implementation

| Component | Tested hardware / implementation |
| --- | --- |
| SoC | Realtek RTL9303 revision B (6487), 800 MHz |
| Memory | 128 MiB RAM |
| Flash | 16 MiB Winbond SPI NOR, JEDEC EF4018; SPI at 25 MHz |
| Network | Eight SFP+ cages; physical ports 1–8 correspond to lan1–lan8 |
| MAC / SerDes indices | MAC 0,8,16,20,24,25,26,27; SerDes 2–9 |
| Module control | RTL8231 on auxiliary MDIO address 0; hardware I2C module access |
| MAC address | Per-device ethaddr from the BDINFO U-Boot environment via NVMEM |
| Port LEDs | Hardware scan engine, configured from the original board profile |
| Reset | Internal GPIO5, active low; gpio-keys / KEY_RESTART |
| SYS / PWR | Observed blinking / steadily lit; not explicitly declared as GPIO LEDs |
| Console | 115200 baud |
| Bootloader tested | U-Boot 2011.12.(1.0.0.2), Mar 21 2025 |

The patch adds a dedicated DTS and image definition. It uses existing OpenWrt drivers, without board-specific networking driver patches. The original loader and all flash outside the stock RUNTIME partition are preserved.

Networking defaults are generated by the Realtek target: all eight ports in the default LAN, management at 192.168.1.1/24, and no private VLAN layout, credentials, fixed per-unit MAC or jumbo MTU. LuCI is optional and not included in the supplied minimal configuration. L3/PPPoE performance is outside this port's validation.
